Como criar a chave (uma vez em cada aparelho)

  1. Abra github.com/settings/personal-access-tokens/new.
  2. Token name: app passagens. Expiration: a que preferir (ex.: No expiration).
  3. Repository access: Only select repositories → escolha o repositório do monitor.
  4. Permissions → Add permissions: marque Actions e Contents e mude as duas para Read and write (o Metadata entra sozinho).
  5. Toque em Generate token e confirme; copie a chave (github_pat_…) e cole acima.

A chave fica guardada só neste aparelho e só dá acesso a esse repositório.
